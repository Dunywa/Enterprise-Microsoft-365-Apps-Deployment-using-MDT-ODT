# Phase 3 - Office Deployment Tool (ODT) Setup

Downloaded and configured the Microsoft Office Deployment Tool (ODT) to prepare Microsoft 365 Apps for enterprise deployment.

## Overview

The Office Deployment Tool (ODT) was downloaded from Microsoft and extracted to the central deployment repository hosted on the Domain Controller. This repository will be used by MDT and Group Policy to deploy Microsoft 365 Apps silently to domain-joined computers.

## Tasks Completed

* Downloaded the Office Deployment Tool (ODT)
* Extracted ODT to the deployment repository
* Created the Office deployment folder
* Verified the required deployment files

## Folder Structure

```text
D:\Deploy
│
└── Office
    ├── setup.exe
    └── configuration.xml
```
